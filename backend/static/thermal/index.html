    How was this calculated?

    Emotion, valence and arousal come from the RGB photo (MTCNN face detector + EmotiEffLib), exactly as on the emotion pages. The thermal frame is cropped to the face (found from skin temperature, 30–40 °C), rendered as a white-hot grayscale image and passed to the M3MSTL model (ResNet-50 + Vision Transformer, trained on the TFD68 thermal face dataset), which predicts 68 facial landmarks and whether each is occluded. Temperatures are read from the camera's temperature map: a 3×3 median at each landmark, and min / mean / max over each facial region. The released model does not use temperature itself; it works from the image.
